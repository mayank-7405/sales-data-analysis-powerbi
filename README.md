# Sales Data Analysis Dashboard

An interactive Business Analytics dashboard developed using Power BI to analyze sales performance, profitability, products, customers, promotions, and geographical trends.

## 📊 Project Overview

This project focuses on cleaning, transforming, and analyzing raw sales data to generate meaningful business insights through an interactive Power BI dashboard.

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- Data Cleaning & Transformation
- Data Visualization
- Business Analytics

## 🔍 Analysis Performed

- Top and Bottom 5 products by Sales, Profit, and Quantity Sold
- Sales trends across daily, monthly, quarterly, and yearly periods
- Profit vs. Net Sales relationship
- Sales, Profit, and Quantity comparison across selected periods
- Average discount by promotion category
- Total number of orders
- City-wise sales analysis
- Order-level sales and customer analysis

## 🎯 Dashboard Features

- Interactive date filters
- Product and customer filters
- Promotion category filters
- Dynamic sales, profit, and quantity analysis
- Interactive visualizations for detailed business analysis
